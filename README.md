# Eden

**Eden is an independent, local-first memory engine designed to become ADAM's persistent memory system.**

## Mission

Build an original, free, reliable memory engine that preserves knowledge across conversations, connects related information, supports ongoing projects, and retrieves relevant context without requiring a paid cloud service.

## Core Principles

- **Local-first:** Core memory operations work on the local device.
- **Persistent:** Memories survive application and device restarts.
- **Connected:** Related facts, conversations, decisions, and projects can link together.
- **Traceable:** Memories retain source information and distinguish verified facts from inferences.
- **Correctable:** Memories can be updated, superseded, or deleted.
- **Recoverable:** The database can be backed up and restored.
- **Resource-conscious:** Designed for Android and Termux, with minimal dependencies.
- **Independent:** Developed and tested separately before integration with ADAM.
- **Free to operate:** Core functionality must not require a paid service or AI API.

## Planned Capabilities

1. Persistent knowledge and personal memory.
2. Episodic and conversational memory.
3. Project and procedural memory.
4. Relationships between memories.
5. Search and relevance-ranked retrieval.
6. Memory verification, correction, and consolidation.
7. Backup, restoration, and integrity checking.
8. A stable interface for ADAM integration.

## Development Policy

Build incrementally. Test every component. Preserve source evidence. Never claim a capability is complete until its acceptance tests pass.

## Current Status

The Eden memory engine is implemented, integrated, and has completed its
project acceptance and verification process. The repository contains the
engine source, architecture and API documentation, and automated tests.

Eden is designed for local-first operation and integration with ADAM.
Runtime databases, personal memory records, local backups, and generated
verification artifacts are intentionally excluded from source control.
