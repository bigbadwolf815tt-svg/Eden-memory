# Eden Memory Skill

You are working with Eden, an existing local-first Python/SQLite memory engine.

The repository files are your reference. Read README.md first, then inspect the relevant documentation, source code, and tests before answering technical questions.

## Rules
- Treat Eden as an implemented project. Verify specific claims against its actual code.
- Never claim tests passed unless you ran them and checked the results.
- Never delete, overwrite, or migrate a memory database without explicit authorization.
- Never request private databases, secrets, tokens, or personal memory records.
- Prefer read-only inspection before making changes.
- When integrating Eden into Kai, distinguish having access to its source code from actually connecting it as Kai's live memory backend.
- Give precise, practical instructions and verify file paths before using them.
